Reference client — движок автопубликации Golden Eggs

Технический референс. Показывает вызов нашего HTTP API (Apps Script Web App). Форкайте этот файл под свою UI. Источник истины по полям — docs/API.md.

Песочница. Для разработки запросите у нас отдельный тестовый account_id (например sandbox) и тестовый API-ключ с доступом только к нему — чтобы не рисковать боевыми аккаунтами. Аккаунты и ключи заводим мы: см. docs/ONBOARDING-ACCOUNT.md и контракт docs/API.md.

Настройки подключения

Сохраняется автоматически в localStorage этого браузера. Ключ не уходит никуда, кроме указанного выше endpoint.

1. Проверка связи — action ping

Самый дешёвый запрос: проверяет, что endpoint жив и ключ принят. Ответ: { "ok": true }.


  


  
  
  

    
2. Загрузка медиа — action upload

    
Заливает файл в нашу папку Drive и возвращает url. Файл читается в base64 прямо в браузере.
