# Золотые яйца — пульт публикаций

Единое окно для Дмитрия (запуск) и Ани (пиар), через которое оба ведут публикации сериала «Золотые яйца» в Instagram, Facebook, Telegram и других соцсетях. Google-таблица служит общей памятью, дашборд — удобный интерфейс над ней.

## Структура проекта

```
goldeneggs-control/
├── README.md              ← вы здесь
├── dashboard.html         ← пульт (открывается в браузере)
├── apps_script.gs         ← backend-скрипт для Google-таблицы
├── docs/
│   ├── SETUP.md           ← как подключить пульт к Google-таблице
│   └── VSCODE.md          ← как работать с проектом в VS Code
└── .vscode/
    ├── extensions.json    ← рекомендованные расширения
    └── settings.json      ← настройки редактора
```

## Что куда

| Файл | Куда идёт | Кто работает |
|---|---|---|
| `dashboard.html` | открывается в браузере (локально или с Netlify/Vercel) | Дмитрий, Аня |
| `apps_script.gs` | вставляется в редактор Apps Script внутри Google-таблицы | один раз настраивает Дмитрий |
| `docs/SETUP.md` | прочитать перед подключением | Дмитрий |
| `docs/VSCODE.md` | прочитать перед открытием в VS Code | Дмитрий |

## С чего начать

1. Откройте папку в VS Code: **File → Open Folder…** и выберите `goldeneggs-control`. Подробнее в `docs/VSCODE.md`.
2. Подключите пульт к Google-таблице по инструкции в `docs/SETUP.md` (~5 минут, один раз).
3. Откройте `dashboard.html` в браузере (правый клик в VS Code → **Open with Live Server**, если установили расширение Live Server).
4. Вкладка **Настройки** → вставьте URL Apps Script → «Подключить и загрузить».
5. Готово. Все 20 публикаций подтянутся, любая правка пишется обратно в таблицу.

## Режимы работы

- **Онлайн** (URL Apps Script указан): таблица — общая память. Что меняет Аня — через ~45 секунд видно у вас, и наоборот. Кнопкой ⟳ — сразу.
- **Локально** (URL не указан): дашборд хранит изменения в localStorage браузера. Синхронизация — вручную через Экспорт ↑ / Импорт ↓.

## Возможности пульта

- Календарь и список постов с фильтрами по площадке/статусу/типу.
- Кнопка «Скопировать пост» — текст + хэштеги одним кликом в буфер.
- Кнопки быстрого перехода в форму создания поста (Instagram / Facebook / Telegram / TikTok / YouTube / VK).
- Чек-лист публикации с прогресс-баром на каждой карточке.
- Статусы: черновик → на ревью → готов → опубликован.
- Отдельная вкладка для Ани — что у неё в работе, что ждёт правок.
- Таймер до премьеры.

## Дальше

После премьеры этот же дашборд можно использовать для следующих сезонов: создаёте новый Google-лист (или новый файл), меняете `SHEET_NAME` в `apps_script.gs`, переразвёртываете — и снова поехали.
