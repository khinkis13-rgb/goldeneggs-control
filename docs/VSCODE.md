# Работа с проектом в VS Code

Этот документ — для Дмитрия (или того, кто будет править файлы). Аня может не читать: ей достаточно открыть `dashboard.html` в браузере.

## Шаг 1. Установить VS Code

Если ещё не установлен — скачайте с [code.visualstudio.com](https://code.visualstudio.com/). Бесплатно, есть версии для Mac, Windows, Linux.

## Шаг 2. Открыть проект

Способ А — через VS Code:

1. Запустите VS Code.
2. Меню **File → Open Folder…** (на Mac: ⌘O).
3. Выберите папку `goldeneggs-control` и нажмите **Open**.
4. Если VS Code спросит «Do you trust the authors of the files…» — нажмите **Yes, I trust the authors**.

Способ Б — через терминал:

```bash
cd путь/к/goldeneggs-control
code .
```

(Команда `code` появляется после установки VS Code; на Mac её можно включить через Command Palette → «Shell Command: Install 'code' command in PATH».)

## Шаг 3. Установить рекомендованные расширения

При первом открытии папки VS Code в правом нижнем углу предложит установить расширения из `.vscode/extensions.json`. Нажмите **Install All**. Если не предложил — откройте панель **Extensions** (⇧⌘X) и найдите эти три вручную:

- **Live Server** (Ritwick Dey) — открывает HTML в браузере и обновляет страницу при сохранении.
- **Google Apps Script Color** (HiraokaHyperTools) — подсветка синтаксиса для `.gs`-файлов (не обязательно, но удобно).
- **Markdown All in One** (Yu Zhang) — для просмотра `.md`-файлов в человеческом виде (⇧⌘V — превью).

## Шаг 4. Посмотреть, что в проекте

В левой панели **Explorer** (⇧⌘E) — дерево файлов:

- `dashboard.html` — сам пульт. Главный рабочий файл. ~1700 строк (CSS + HTML + JS).
- `apps_script.gs` — серверный код для Google-таблицы. Локально не запускается, ставится только в Apps Script.
- `README.md` — про проект.
- `docs/SETUP.md` — подключение к Google-таблице.
- `docs/VSCODE.md` — этот файл.

## Шаг 5. Запустить дашборд в браузере

Самый удобный способ — через Live Server:

1. Правый клик на `dashboard.html` в Explorer.
2. **Open with Live Server**.
3. В браузере откроется ваш пульт на адресе `http://127.0.0.1:5500/dashboard.html`. Любая правка файла — страница сама перезагружается.

Альтернатива без Live Server:

- В Explorer правый клик → **Reveal in Finder** (Mac) / **Open Containing Folder** (Win). Двойной клик по `dashboard.html` — откроется в браузере по умолчанию.

## Шаг 6. Редактировать дашборд

Структура `dashboard.html`:

- `<head>` — мета и большой блок `<style>` с CSS-переменными (цвета в `:root{--gold...}` сверху).
- `<body>` — разметка: шапка, табы, фильтры, секции `#sec-today`, `#sec-cal`, `#sec-all`, `#sec-anya`, `#sec-settings`, `#sec-help`.
- `<script>` — данные `SEED_POSTS`, `DEFAULT_SETTINGS`, функции `render*`, обработчики событий, онлайн-режим (`api`, `loadFromBackend`, `pushField`).

Полезные точки для правок:

| Что | Где найти | Подсказка |
|---|---|---|
| Цвет фона / золото | `:root{...}` в начале `<style>` | поменять `--bg`, `--gold`, `--cream` |
| Слова в чек-листе | `CHECK_LABELS = {...}` в `<script>` | добавить новый ключ — появится во всех карточках |
| Базовые хэштеги | `DEFAULT_SETTINGS.baseHashtags` | (но удобнее править через вкладку Настройки) |
| Дата премьеры | `DEFAULT_SETTINGS.premiere` | формат `YYYY-MM-DD` |
| Площадки | `PLATFORM_ACTIONS = {...}` | добавить ключ — появится в фильтре и кнопках |

После сохранения файла (⌘S) Live Server сам обновит страницу.

## Шаг 7. Поправить серверный код (`apps_script.gs`)

Локально его запустить нельзя — он работает только в редакторе Apps Script внутри Google-таблицы.

Рабочий цикл:

1. Открыли файл в VS Code, поправили.
2. Скопировали всё содержимое (⌘A → ⌘C).
3. Открыли таблицу → **Расширения → Apps Script** → вставили (⌘A → ⌘V), сохранили (⌘S).
4. **Развернуть → Управление развертываниями** → пиктограмма карандаша на существующем развёртывании → версия: **Новая версия** → **Развернуть**. URL не меняется.
5. В пульте нажмите ⟳ — увидите обновлённые данные.

## Шаг 8 (опционально). Версионирование через Git

Чтобы хранить историю правок и не потерять файл:

```bash
cd goldeneggs-control
git init
git add .
git commit -m "Initial dashboard"
```

Можно загрузить в приватный репозиторий на GitHub — заодно получите бесплатный хостинг через **GitHub Pages**: Settings → Pages → выбрать ветку → дашборд будет доступен по `https://yourname.github.io/goldeneggs-control/dashboard.html`.

## Частые вопросы

**Где хранятся локальные правки в дашборде?**
В `localStorage` браузера. Если работает онлайн-режим (URL Apps Script указан) — в Google-таблице.

**Можно ли работать одновременно с Аней?**
Да, если включён онлайн-режим. Изменения синхронизируются каждые ~45 секунд (или сразу по ⟳).

**Что если файл стал слишком большой?**
~1700 строк — нормально для одностраничного приложения. Если хочется разбить на отдельные .css/.js — стандартный подход в VS Code:
1. Создайте `dashboard.css` и `dashboard.js`.
2. Перенесите содержимое `<style>` в .css, `<script>` в .js.
3. В HTML замените на `<link rel="stylesheet" href="dashboard.css">` и `<script src="dashboard.js"></script>`.
4. **Важно**: при таком разбиении файл больше нельзя будет открыть двойным кликом — только через Live Server или хостинг. Сейчас же это монофайл, его можно отправлять Ане одним файлом — удобнее.

**Можно ли использовать AI-помощника прямо в VS Code?**
Да: расширения **GitHub Copilot** или **Continue** (open source) — отвечают на вопросы по коду, дописывают функции. На этапе доработки очень помогают.
