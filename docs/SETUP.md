# Золотые яйца — подключение пульта к Google-таблице

Делается один раз, занимает ~5 минут. После этого Google-таблица становится общей памятью: всё, что меняет Дмитрий или Аня в пульте, мгновенно пишется в таблицу и подтягивается у другого.

## Что вам понадобится

- Файл `apps_script.gs` (рядом с этим документом) — backend-скрипт.
- Файл `dashboard.html` — пульт.
- Аккаунт Google (тот, что владеет таблицей).
- Браузер на компьютере для настройки (телефон не подойдёт — Apps Script на мобильном неудобен).

## Шаг 1. Установить скрипт в таблицу

1. Откройте вашу Google-таблицу с расписанием.
2. В меню сверху: **Расширения → Apps Script**. Откроется новая вкладка с редактором.
3. В редакторе удалите весь код, который там есть (обычно одна функция-заготовка `function myFunction()`).
4. Откройте файл `apps_script.gs`, скопируйте всё содержимое и вставьте в редактор.
5. Нажмите значок дискеты или `Ctrl/Cmd + S` для сохранения. Имени проекту можно дать любое, например `Goldeneggs backend`.

## Шаг 2. Дать скрипту разрешения и подготовить колонки

1. В редакторе сверху есть выпадающий список с именами функций. Выберите `initSheet`.
2. Нажмите кнопку **▶ Выполнить**.
3. Google попросит разрешения:
   - Выберите свой аккаунт (тот, которому принадлежит таблица).
   - На экране «Google не подтвердил это приложение» нажмите **«Дополнительные настройки»** → **«Перейти к проекту (небезопасно)»** → **«Разрешить»**.
   - Это нормально: «небезопасно» здесь означает «не приложение из магазина». На деле скрипт работает только с вашей собственной таблицей.
4. После выполнения в таблице на листе «инст» появятся новые колонки G–K: Статус, Хэштеги, Ответственный, Чек-лист (JSON), Заметки. Если они уже были — ничего не сломается.

## Шаг 3. Опубликовать скрипт как Web App

1. В редакторе сверху нажмите **Развернуть → Новое развертывание**.
2. В открывшемся окне слева — шестерёнка ⚙ напротив «Выбрать тип»: выберите **Веб-приложение**.
3. Поля:
   - **Описание**: например, `Goldeneggs API` (не важно).
   - **Запускать от имени**: `Я ([ваш email])`.
   - **Кто имеет доступ**: **Все** (это значит «у кого есть ссылка», публично таблица при этом не открывается — пишет только через ваш аккаунт).
4. Нажмите **Развернуть**.
5. Появится длинная ссылка вида `https://script.google.com/macros/s/AKfycb.../exec`. Скопируйте её.

## Шаг 4. Подключить пульт

1. Откройте `dashboard.html` в браузере (Safari/Chrome/любой).
2. Вкладка **Настройки**.
3. Поле **URL Apps Script** — вставьте скопированную ссылку.
4. Нажмите **«Подключить и загрузить»**.
5. В правом верхнем углу появится зелёная плашка `✓ Online · 20 постов`. Все посты подтянутся.

## Шаг 5. Подключить Аню

1. Передайте Ане `dashboard.html` и ту же ссылку Apps Script.
2. Она открывает пульт у себя, вкладка Настройки → вставляет ссылку → «Подключить и загрузить».
3. Теперь вы работаете с одной памятью: что один пишет — у второго видно через ⟳ (или само через ~45 секунд).

## Что делать, если что-то пошло не так

- **«Бэкенд вернул не JSON»**: ссылка скопирована не до конца, или развёрнутая версия — старая. Зайдите в Apps Script → Развернуть → Управление развертываниями → создайте новую версию.
- **«Лист «инст» не найден»**: в верхней части `apps_script.gs` поправьте `SHEET_NAME` на имя вашего листа.
- **`✓ Online`, но постов 0**: убедитесь, что данные на листе начинаются с 6-й строки (если у вас другая структура — поправьте `FIRST_DATA_ROW` в скрипте).
- **Изменения не записываются**: проверьте, что развернуто как «Все» (а не «Только я»).

## Безопасно ли это

Скрипт развёрнут с правами «запуск от имени Я». То есть кто угодно с ссылкой может через ваш скрипт читать и менять **только тот лист**, который вы указали в `SHEET_NAME`. Ссылка длинная и случайная — её фактически невозможно подобрать. Если вдруг утечёт — отключите развёртывание в редакторе Apps Script одним кликом (Развернуть → Управление развертываниями → «Отключить»).
